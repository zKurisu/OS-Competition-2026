## 规则

1. **不许在本文件里写"约 / 大概"**：要么给出确切数字，要么在正文用 `#abl[...]` 标成待测。
2. **缺项写 `—`**，并在正文说明为什么缺（例：`clock_gettime` / `nanosleep0` 只在修复前测过，
   所以 `ours` 一列为空）。
3. **同名不同板/不同镜像要区分**：本表的 `ours` 默认指最终镜像 `starry-final.sd`；
   如果某个数字来自更早的镜像（例如修复前的 2 MiB 档），在该行注释里写明。
